# Student Performance Analytics System

## 1. Project Overview

The Student Performance Analytics System is a Python-based data analysis project developed to analyze student academic performance using Python, NumPy, Pandas, and Matplotlib.

The system processes student information and subject marks to calculate totals, averages, grades, pass/fail results, and performance statistics. It also identifies top-performing students and displays analysis using charts.

## 2. Objective

The main objective of this project is to analyze student academic performance and generate meaningful information from student data. It helps identify the best-performing students, compare subject performance, and understand department-wise results.

## 3. Technologies Used

* **Python:** Main programming language.
* **NumPy:** Numerical calculations and statistical analysis.
* **Pandas:** Dataset loading, processing, and analysis.
* **Matplotlib:** Creating charts and visualizations.
* **Jupyter Notebook:** Writing and executing the project code.

## 4. Dataset Description

The project uses a dataset containing 20 student records.

The dataset includes the following columns:

* Student_ID
* Name
* Department
* Python
* NumPy
* Pandas
* Attendance

The original dataset is stored in `students.csv`.

## 5. Implementation

The project is implemented through the following steps:

1. Import NumPy, Pandas, and Matplotlib.
2. Load student records using Pandas.
3. Calculate total marks for each student.
4. Calculate average marks using NumPy.
5. Assign grades using a user-defined function.
6. Determine pass/fail status using conditional statements.
7. Calculate class performance statistics.
8. Analyze subject-wise and department-wise averages.
9. Identify the top five performing students.
10. Create charts to visualize the results.
11. Save the processed data into a new CSV file.

## 6. Key Features

* Student dataset management.
* Total and average marks calculation.
* Automatic grade assignment.
* Pass/fail analysis.
* Highest, lowest, and overall average performance.
* Subject-wise performance comparison.
* Department-wise performance analysis.
* Identification of top-performing students.
* Graphical representation of results.
* Export of analyzed student data.
